# 利好政策！成都13-14岁在校适龄女孩接种HPV疫苗 ——选择国产疫苗可享受免费政策！

> 更新时间：2026-09-16 (UTC+8)

//  

宫颈癌是全球妇科常见肿瘤之一，据研究数据表明，2020年中国宫颈癌新发病例位居全球第二。

2020年，世界卫生组织发布《加速消除宫颈癌全球战略》，提出到2030年，90%的人群要在15岁之前完成HPV疫苗接种的目标。

2021年11月，成都正式启动在校适龄女孩HPV疫苗接种工作，截至目前，我市已有11万余名在校适龄女孩参与接种。

今年，又有新的好消息！2022年9月，成都市卫健委、市教育局、市财政局对《成都市宫颈癌综合防控HPV疫苗接种实施方案》进行修订，除依旧按照“知情同意、自主选择、自愿接种”原则、坚持600元/人的补助标准不变外，成都还将今年新上市的国产二价HPV疫苗“沃泽惠”纳入项目用苗，选择该款疫苗将实现疫苗免费，惠及更多在校适龄女孩。

**1**

**为什么要接种HPV疫苗？**

**答**

宫颈癌与人乳头瘤病毒（HPV）持续感染密切相关，近年来呈现低龄化趋势，成为影响女性健康的“重大杀手”，对家庭和社会造成沉重负担。而接种HPV疫苗能够降低疫苗相关型疾病风险，并且在从未感染过HPV的女性人群中效果更明显。因此，在感染高风险的年龄前接种疫苗，能够最大程度地减少感染和传播几率。

**2**

**成都在校适龄女孩HPV疫苗惠民项目覆盖哪些人群？**

**答**

当年13-14岁的在校适龄女孩，以接种首剂HPV疫苗时年满13周岁未满15周岁计算（2022年接种对象出生日期为2008年1月1日—2009年12月31日），且无HPV疫苗接种史的，即可享受我市对在校适龄女孩的HPV疫苗惠民项目。

**3**

**惠民项目包含哪几种HPV疫苗？**

**答**

目前，国内适合13-14岁年龄段接种的HPV疫苗共有4个品规，分别为国产二价（沃泽惠、馨可宁）、进口二价（希瑞适）、进口四价（佳达修），均已纳入成都市在校适龄女孩HPV疫苗接种项目。

**4**

**不同的HPV疫苗有什么区别？**

**答**

HPV疫苗的“价”指的是所针对病毒型别的数量。目前已知的HPV型别约有200种，分为高危型别和低危型别，国内最常见的高危型别以HPV16型和18型为主，他们是导致宫颈鳞状细胞癌和腺癌最常见的两种类型。因此，有效预防HPV16型和18型感染是宫颈癌一级预防的重点。二价、四价HPV疫苗均覆盖HPV16型、18型，无论选择哪种HPV疫苗，只要接种了就好。

**5**

**我市在校适龄女孩怎么参与HPV疫苗接种惠民项目？**

**答**

2022年在校适龄女孩HPV疫苗接种项目摸底登记工作已在各区（市）县陆续开展，开学后家长们选择疫苗品种、填写接种意愿后，将由学校所在地预防接种单位负责安排时间，以学校为单位在学校所在地的预防接种门诊进行接种。

**温馨提示：**

接种年龄越小、越早，保护效果越好。请家长朋友们提前了解，让孩子积极参与HPV疫苗接种项目。
